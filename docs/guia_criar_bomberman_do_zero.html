Guia passo a passo

Como criar do zero um Bomberman em Java, no terminal, usando Programacao Orientada a Objetos

Objetivo

Este guia mostra a ordem recomendada para criar o jogo do zero no IntelliJ. A ideia e chegar em um jogo igual ao projeto de exemplo: sem interface grafica, rodando no terminal, com matriz, jogador, inimigos, bombas, explosoes, poderes, saida e salvamento.

O melhor jeito de aprender e criar as classes em etapas pequenas. Em cada etapa, compile e rode o programa. Assim voce encontra erros cedo e entende o papel de cada classe.

1. Criando o projeto no IntelliJ

  1. Abra o IntelliJ IDEA.
  2. Clique em New Project.
  3. Escolha Java.
  4. Use JDK 17 ou superior. Se tiver Java 21, pode usar.
  5. Nome sugerido: BombermanTerminal.
  6. Crie o projeto.
  7. Dentro de src, crie a classe Principal.

Para facilitar no comeco, voce pode criar todas as classes no pacote padrao, sem package. Depois, se quiser organizar melhor, pode criar pacotes como model, game e io.

2. Ordem recomendada das classes

Ordem Classe/enum/interface Para que serve
1 Principal Inicia o programa e mostra o menu principal.
2 Direcao, Terreno, Dificuldade, Poder Guardam valores fixos: direcoes, tipos de celula, dificuldade e poderes.
3 Posicao Representa linha e coluna dentro da matriz.
4 Celula Representa uma casa do tabuleiro.
5 Tabuleiro Representa a matriz do jogo.
6 Destrutivel, Entidade, Jogador Cria a base dos personagens e o jogador.
7 Inimigo, InimigoComum, InimigoRastreador, InimigoSabotador Cria os tres tipos de inimigos usando heranca e polimorfismo.
8 Bomba, Chama Controlam bomba, temporizador e fogo da explosao.
9 Jogo Controla a partida, os turnos e as regras.
10 FabricaMapa Gera mapas aleatorios.
11 SalvamentoJogo Salva e carrega arquivos.
12 Excecoes personalizadas Tratam movimentos invalidos e limite de bombas.

3. Etapa 1 - Criar o Principal e o menu

Comece com um menu simples. Ainda nao crie o jogo completo. O objetivo desta etapa e apenas abrir o programa, ler opcao do usuario e chamar o jogo quando a opcao for "Jogar". 

import java.util.Scanner;

public class Principal {
    public static void main(String[] argumentos) {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.println("==== BOMBERMAN POO ====");
            System.out.println("1 - Jogar");
            System.out.println("2 - Sair");
            System.out.print("Escolha: ");

            String opcao = scanner.nextLine();

            if (opcao.equals("1")) {
                System.out.println("Aqui vamos iniciar o jogo.");
            } else if (opcao.equals("2")) {
                break;
            } else {
                System.out.println("Opcao invalida.");
            }
        }
    }
}

Teste antes de continuar. Se o menu abre e fecha corretamente, siga para a proxima etapa.

4. Etapa 2 - Criar enums basicos

Enums evitam usar textos soltos pelo codigo. Eles deixam o programa mais organizado e mais facil de apresentar. 

public enum Terreno {
    CHAO, PAREDE, CAIXOTE
}
public enum Dificuldade {
    FACIL, NORMAL, DIFICIL
}
public enum Poder {
    BOMBA_EXTRA, RAIO_EXTRA
}
public enum Direcao {
    CIMA(-1, 0), BAIXO(1, 0), ESQUERDA(0, -1), DIREITA(0, 1);

    private final int deltaLinha;
    private final int deltaColuna;

    Direcao(int deltaLinha, int deltaColuna) {
        this.deltaLinha = deltaLinha;
        this.deltaColuna = deltaColuna;
    }

    public int deltaLinha() {
        return deltaLinha;
    }

    public int deltaColuna() {
        return deltaColuna;
    }
}

5. Etapa 3 - Criar Posicao

A classe Posicao representa uma coordenada da matriz. Ela evita passar linha e coluna separadas em todos os metodos. 

public class Posicao {
    private final int linha;
    private final int coluna;

    public Posicao(int linha, int coluna) {
        this.linha = linha;
        this.coluna = coluna;
    }

    public int getLinha() {
        return linha;
    }

    public int getColuna() {
        return coluna;
    }

    public Posicao mover(Direcao direcao) {
        return new Posicao(linha + direcao.getDeltaLinha(), coluna + direcao.getDeltaColuna());
    }

    public boolean mesmaCoordenada(Posicao outra) {
        return outra != null
                && linha == outra.getLinha()
                && coluna == outra.getColuna();
    }
}

Quando precisar comparar coordenadas, use mesmaCoordenada.

6. Etapa 4 - Criar Celula

Uma celula sabe se e chao, parede ou caixote. Ela tambem pode esconder poder ou saida. 

public class Celula {
    private Terreno terreno;
    private Poder poder;
    private boolean exit;
    private boolean exitRevealed;

    public Celula(Terreno terreno) {
        this.terreno = terreno;
    }

    public Terreno obterTerreno() {
        return terreno;
    }

    public void definirTerreno(Terreno terreno) {
        this.terreno = terreno;
    }

    public void definirPoder(Poder poder) {
        this.poder = poder;
    }

    public boolean temPoderEscondido() {
        return terreno == Terreno.CAIXOTE && poder != null;
    }

    public Poder obterPoderVisivel() {
        if (terreno == Terreno.CHAO) {
            return poder;
        }
        return null;
    }

    public void removerPoder() {
        poder = null;
    }

    public boolean hasExit() {
        return exit;
    }

    public void setExit(boolean exit) {
        this.exit = exit;
    }

    public boolean isExitRevealed() {
        return exitRevealed;
    }

    public void revealExit() {
        exitRevealed = true;
    }
}

7. Etapa 5 - Criar Tabuleiro

O Tabuleiro e a matriz. Ele deve saber verificar limites, paredes, caixotes e imprimir uma versao visual. 

public class Tabuleiro {
    private final Celula[][] celulas;

    public Tabuleiro(int tamanho) {
        celulas = new Celula[tamanho][tamanho];
        for (int linha = 0; linha < tamanho; linha++) {
            for (int coluna = 0; coluna < tamanho; coluna++) {
                celulas[linha][coluna] = new Celula(Terreno.CHAO);
            }
        }
    }

    public int tamanho() {
        return celulas.length;
    }

    public boolean dentroDosLimites(Posicao posicao) {
        return posicao.linha() >= 0
            && posicao.linha() < tamanho()
            && posicao.coluna() >= 0
            && posicao.coluna() < tamanho();
    }

    public Celula celulaEm(Posicao posicao) {
        return celulas[posicao.linha()][posicao.coluna()];
    }

    public boolean ehParede(Posicao posicao) {
        return dentroDosLimites(posicao) && celulaEm(posicao).obterTerreno() == Terreno.PAREDE;
    }

    public boolean ehCaixote(Posicao posicao) {
        return dentroDosLimites(posicao) && celulaEm(posicao).obterTerreno() == Terreno.CAIXOTE;
    }

    public boolean estaBloqueado(Posicao posicao) {
        return ehParede(posicao) || ehCaixote(posicao);
    }
}

Depois acrescente o metodo toMatrix, que transforma o tabuleiro em caracteres: X parede, # caixote, . chao, * poder e O saida.

8. Etapa 6 - Criar jogador e entidade base

Aqui aparecem encapsulamento, composicao e heranca. Primeiro crie uma interface e uma classe abstrata. 

public interface Destrutivel {
    void receberExplosao(Jogo game);
}
public abstract class Entidade implements Destrutivel {
    private Posicao posicao;

    protected Entidade(Posicao posicao) {
        this.posicao = posicao;
    }

    public Posicao obterPosicao() {
        return posicao;
    }

    public void setPosicao(Posicao posicao) {
        this.posicao = posicao;
    }
}

Agora crie o jogador:

public class Jogador extends Entidade {
    private final String nome;
    private int lives = 3;
    private int bombLimit = 1;
    private int explosionRadius = 1;
    private int hintsUsed;
    private int pontos;

    public Jogador(String nome, Posicao posicao) {
        super(posicao);
        this.nome = nome;
    }

    public String getName() { return nome; }
    public int getLives() { return lives; }
    public int getLimiteBombas() { return bombLimit; }
    public int obterRaioExplosao() { return explosionRadius; }
    public int getHintsUsed() { return hintsUsed; }
    public int getScore() { return pontos; }

    public void loseLife() { lives--; }
    public void useHint() { hintsUsed++; }
    public void addScore(int value) { pontos += value; }

    public void aplicar(Poder poder) {
        if (poder == Poder.BOMBA_EXTRA) {
            bombLimit++;
        } else if (poder == Poder.RAIO_EXTRA) {
            explosionRadius++;
        }
        addScore(50);
    }
}

9. Etapa 7 - Criar inimigos

Crie uma classe abstrata Inimigo. Cada inimigo tera o mesmo tipo geral, mas comportamento diferente. Isso e polimorfismo. 

public abstract class Inimigo extends Entidade {
    protected Inimigo(Posicao posicao) {
        super(posicao);
    }

    public abstract char getSymbol();
    public abstract void agir(Jogo game);
    public abstract Inimigo copia();
}

Depois crie:

  • InimigoComum: anda aleatoriamente, mais devagar.
  • InimigoRastreador: se ve o jogador na mesma linha ou coluna, persegue.
  • InimigoSabotador: se achar bomba recente ao lado, camufla a bomba.
public class InimigoComum extends Inimigo {

        super(posicao);

        return 'C';

        }
    }

    public Inimigo copia() {
        return new InimigoComum(obterPosicao());
    }
}

Nessa etapa, voce ainda pode deixar os metodos incompletos. A movimentacao dos inimigos sera finalizada quando a classe Jogo existir.

10. Etapa 8 - Criar Bomba e Chama

A bomba precisa guardar posicao, tempo, raio e se foi camuflada pelo sabotador.

public class Bomba {
    private final Posicao posicao;
    private int temporizador;
    private final int raio;
    private boolean camouflaged;

    public Bomba(Posicao posicao, int temporizador, int raio) {
        this.posicao = posicao;
        this.temporizador = temporizador;
        this.raio = raio;
    }

    public Posicao obterPosicao() { return posicao; }
    public int getTimer() { return temporizador; }
    public int getRadius() { return raio; }
    public boolean isCamouflaged() { return camouflaged; }

    public void decreaseTimer() {
        temporizador--;
    }

    public void camouflage() {
        camouflaged = true;
    }
}
public class Chama {
    private final Posicao posicao;
    private int duracao;

    public Chama(Posicao posicao, int duracao) {
        this.posicao = posicao;
        this.duracao = duracao;
    }

    public Posicao obterPosicao() { return posicao; }
    public int getDuration() { return duracao; }
    public void decrease() { duracao--; }
}

12. Etapa 10 - Implementar impressao da matriz

Primeiro imprima so o tabuleiro. Depois coloque bombas, fogo, inimigos e jogador por cima da matriz. A ordem recomendada e:

  1. Gerar char[][] a partir do Tabuleiro.
  2. Desenhar bombas com B.
  3. Desenhar fogo com +.
  4. Desenhar inimigos com C, R ou S.
  5. Desenhar jogador com P.
  6. Imprimir linha por linha.

Essa ordem e importante porque o jogador deve aparecer visualmente se estiver na mesma casa de algum efeito.

13. Etapa 11 - Implementar movimento do jogador

Para cada comando, calcule a posicao alvo. Depois verifique:

  1. Se esta fora do mapa, movimento invalido.
  2. Se e parede ou caixote, movimento invalido.
  3. Se tem bomba, movimento invalido.
  4. Se tem inimigo, perde vida.
  5. Se tem poder, aplica o bonus.
  6. Se tem saida revelada e nao ha inimigos, vence.

Crie um metodo parecido com:

private void moverJogador(Direcao direcao) {
    Posicao destino = jogador.obterPosicao().mover(direcao);

    if (!tabuleiro.dentroDosLimites(destino)) {
        System.out.println("Fora do mapa.");
        return;
    }

    if (tabuleiro.estaBloqueado(destino)) {
        System.out.println("Caminho bloqueado.");
        return;
    }

    jogador.setPosicao(destino);
}

14. Etapa 12 - Implementar bombas

Quando o jogador apertar B:

  1. Verifique se ele ainda pode plantar bomba.
  2. Crie new Bomba(jogador.obterPosicao(), 5, jogador.obterRaioExplosao()).
  3. Adicione na lista de bombas.

A cada turno:

  1. Reduza o tempo de cada bomba.
  2. Se o tempo chegar a zero, detone.
  3. Ao detonar, gere fogo no centro e nas quatro direcoes.
  4. Pare a explosao quando bater em parede.
  5. Destrua caixote e pare a explosao naquela direcao.
  6. Mate inimigos atingidos.
  7. Se atingir o jogador, ele perde vida.

15. Etapa 13 - Implementar inimigos

Depois que o jogador faz uma acao valida, chame moveEnemies().

  • Comum: escolhe uma direcao aleatoria livre.
  • Rastreador: se o jogador esta na mesma linha ou coluna sem obstaculos, vai na direcao dele.
  • Sabotador: se existe bomba ao lado e ela ainda esta na metade inicial do tempo, camufla a bomba.

No codigo, o segredo e deixar cada classe decidir seu comportamento dentro de agir(Jogo game). Assim a classe Jogo so percorre a lista: 

for (Inimigo inimigo : inimigos) {
    inimigo.agir(this);
}

Essa linha e muito boa para explicar polimorfismo na apresentacao: o mesmo metodo agir executa comportamentos diferentes dependendo do tipo real do inimigo.

16. Etapa 14 - Criar FabricaMapa

Tire a criacao do mapa de dentro de Jogo. Crie uma classe FabricaMapa responsavel por:

  1. Criar um Tabuleiro 15x15.
  2. Colocar paredes nas bordas.
  3. Colocar paredes fixas nas posicoes pares.
  4. Espalhar caixotes aleatorios.
  5. Esconder a saida em um caixote.
  6. Esconder alguns poderes.
  7. Posicionar inimigos conforme a dificuldade.

Deixe a area inicial livre, por exemplo perto da posicao (1, 1), para o jogador nao nascer preso.

17. Etapa 15 - Criar salvamento

Crie SalvamentoJogo para salvar estado do jogo em dados/jogo_salvo.txt. Salve:

  • Nome, vidas, bomba maxima, raio, dicas e pontuacao.
  • Dificuldade.
  • Turno atual.
  • Tabuleiro.
  • Inimigos vivos.
  • Bombas ativas.

O salvamento nao precisa ser bonito. Ele so precisa ser consistente para o proprio programa conseguir carregar.

19. Etapa 17 - Criar excecoes personalizadas

Crie excecoes para regras do jogo:

public class ExcecaoJogo extends Exception {

public class ExcecaoMovimentoInvalido extends ExcecaoJogo {

    }

public class ExcecaoLimiteBombas extends ExcecaoJogo {

Use essas excecoes quando o jogador tentar andar contra parede, sair do mapa ou plantar bombas alem do limite.

20. Checklist final de funcionamento

Antes de considerar pronto, teste:

  • O menu abre.
  • O jogador consegue digitar nome.
  • A dificuldade facil nao cria sabotador.
  • A matriz aparece no terminal.
  • O jogador anda com W, A, S, D.
  • O jogador nao atravessa parede nem caixote.
  • A bomba aparece com B.
  • A bomba detona depois de 5 turnos.
  • A explosao aparece em cruz.
  • A explosao para em parede.
  • A explosao destroi caixote.
  • Power-up pode ser revelado.
  • A saida pode ser revelada.
  • Inimigos se movem.
  • Rastreador persegue em linha reta.
  • Sabotador camufla bomba.
  • Encostar em inimigo tira vida.
  • Perder todas as vidas termina o jogo.
  • Eliminar inimigos e chegar na saida vence o jogo.
  • Save carrega partida.

21. Como explicar na apresentacao

Use esta fala como base:

"O jogo foi modelado usando Programacao Orientada a Objetos. A classe Jogo controla a partida e e composta por Tabuleiro, Jogador, listas de Inimigo, Bomba e Chama. O Tabuleiro representa a matriz. O Jogador guarda vidas, limite de bombas, raio de explosao, dicas e pontuacao. Os inimigos usam heranca: Inimigo e abstrata e cada subtipo implementa agir de forma diferente. Isso demonstra polimorfismo. Tambem usei interface Destrutivel e excecoes personalizadas para regras do jogo, como movimento invalido e limite de bombas."

23. Dica principal

Nao tente escrever tudo de uma vez. A sequencia correta e: fazer compilar, fazer imprimir, fazer mover, fazer colidir, fazer explodir, fazer inimigos, fazer vencer/perder e so depois salvar em arquivos.
